  K-BIGx 기업혁신성장 보고서 — PDF 템플릿(단독 HTML)
  데이터만 바꾸면 표 · 그래프 · 쪽 나눔 · 목차 · '-' 처리까지 다시 계산해 그린다.
  늘 라이트 모드로 그린다(OS · 브라우저의 다크 설정과 무관).

  [1] 구성 — 바꾸는 곳은 ① 뿐
    ① <script id="kbigx-report-data">   보고서 데이터(JSON). 지금은 목업
    ② <div id="kbigx-report-root">      목업으로 미리 그린 마크업. 열 때 ① 로 다시 그려진다
    ③ 마지막 <script>                    화면 코드

  [2] PDF 만들기
    1. ① 에 JSON 을 넣는다. 이때 '<' 는 \u003c 로 바꿔 넣는다 — 값에 "</script>" 가 있으면 ① 이 끊겨 data-error 가 난다.
         화면에는 '<' 그대로 나온다.
         예) JSON.stringify(data).replace(/</g, '\\u003c')   // JS 기준
    2. 파일을 연다. 고른 장만 만들 때는 주소 뒤에 ?sections=장,장
         briefing 진단브리핑 · company 기업현황 · innovation 기술혁신정보 · tech-index Tech-Index
         credit-finance 신용/재무정보 · activity 활동성정보
         표지 · 목차 · 참고자료는 늘 들어간다. 장 순서는 보고서 순서로 고정. 맞는 이름이 없으면 전체 장.
    3. #kbigx-report-root 에 data-ready="true" 나 data-error 가 붙을 때까지 기다린다.
         보통 1 ~ 2초. 30초가 지나도 둘 다 없으면 실패로 본다.
    4. data-ready  → page.pdf({preferCSSPageSize: true, printBackground: true})   A4 세로
       data-error  → 저장하지 않는다. 속성 값에 데이터 오류 이유가 적힌다.
    ※ 기다리지 않고 저장하면 목업 값이 찍힐 수 있다.
    ※ 외부 파일을 받지 않는다(글꼴 Pretendard · 이미지 · 코드 모두 이 파일 안) — 인터넷이 없어도 된다.
    ※ Pretendard 에 없는 글자(데이터 속 ☆ ◎ 같은 특수기호 · 옛한글 등)만 서버 글꼴로 그린다.
       서버에 한글 글꼴(예: Noto Sans CJK KR)이 하나도 없으면 그 글자는 □ 로 나온다 — 설치를 권장.

  [3] 데이터 기본 규칙
    · 목업 JSON 이 형식 견본 — 키 · 구조는 그대로 두고 값만 바꾼다. 배열 건수는 자유.
    · 값이 없으면 '' · [] · null → 화면이 '-' · 빈 상태로 그린다.
      단 장 · 묶음 객체(creditDetail · techInnovation.holdings 등)는 null 로 보내지 말고 키를 갖춘 채 값만 비운다(null 이면 data-error).
    · 형식: 날짜 "2025-12-04" · 연도 "2024년" · 그래프 시점 "25.10월" · 비율 43.8(% 숫자)
    · 신용/재무정보 · 활동성정보의 연도별 표는 최근 3개년만 그린다(연도를 못 받으면 companyStatus.finance.years 기준).
    · 목록은 자르지 않고 보낸다 — 그려지는 건수는 [7].
    · 필드 이름 주의: techInnovation.competitors[].growthRate 는 화면에 '영업이익률(%)' 로 나온다(이름과 뜻이 다르다).
    · 장별 데이터
        표지          companyName · issuedAt(발급일)
        진단브리핑    company · innovation · techIndex · creditFinance · activity
                      createdAt(기준일자) · subCategoryName(기술혁신정보 제목 옆 분야 태그)
        기업현황      companyStatus        기술혁신정보  techInnovation      Tech-Index  techIndexDetail
        신용/재무정보 creditDetail         활동성정보    activityDetail
        안 쓰임       title · lookupBaseDate
